01 / Disaster Management System

ResQLink

  • Featured project
  • Team project
  • Role: Full-Stack Developer

A web-based disaster management system that helps authorities, volunteers and citizens coordinate during emergencies.

The need
In an emergency, authorities, volunteers and citizens need one shared place to report incidents and organise the response.
What it does
Citizens report incidents, volunteers manage their availability and assignments, and administrators track alerts and resources. Access is role-based, and incidents appear on an interactive map.
My part
Built RESTful APIs with Node.js, Express.js and MySQL, and responsive React.js interfaces with interactive maps.

03 / Web Application

University SGPA Calculator

  • Solo project
  • Role: Developer

A calculator that turns a student's subject grades into their semester GPA and class, built for Software Engineering students at Sabaragamuwa University.

What it does
Students choose a grade for each subject and see their SGPA and class straight away. It runs entirely in the browser with no server, and can export a result sheet as a PDF.
My part
Designed and built it end to end: dynamic grade processing, input validation and result visualisation.
